# Maya Inspire

Website barruulee Afaan Oromoo kan HTML, CSS fi JavaScript qofa fayyadamu.

## Faayilota
- `index.html` — caasaa fuula website
- `style.css` — bifa, halluu fi mobile responsive
- `script.js` — barruulee fakkeenyaa, barbaacha, filannoo gosa, dubbisa guutuu fi kopi gochuu

## Akka itti banamu
1. Faayilota kana hunda galmee tokko keessa kaa'i.
2. `index.html` browser keessatti bani (Chrome, Safari, Firefox ykn Edge).
3. Internet yoo jiraate, qubee Google Fonts irraa fe'amu ni argatta; website'n garuu font bakka bu'aa fayyadamuun offline illee ni banama.

## Barruu haaraa itti dabalu
`script.js` bani. Tarree `articles` keessa object barruu haaraa dabali. Fakkeenya:

```js
{
  id: 9,
  title: "Mata-duree barruu kee",
  category: "Beekumsa",
  date: "26 Onkololeessa 2026",
  read: "Daqiiqaa 3",
  symbol: "✧",
  art: "beekumsa",
  excerpt: "Ibsa gabaabaa barruu kee.",
  body: `Asitti barruu guutuu kee barreessi. Keewwata haaraa gochuuf sarara haaraa fayyadami.`
}
```

`id` adda ta'uu qaba. `category` keessaa tokko fayyadami: `Beekumsa`, `Kaka'umsa`, `Gorsa Jireenyaa`, `Ogbarruu`, `Seenaa`.
`art` keessaa tokko fayyadami: `beekumsa`, `kakaumsa`, `gorsa`, `ogbarruu`, `seenaa`, `afaan`.

## Hubachiisa barbaachisaa
- Kun prototype frontend qofa. Barruuleen `script.js` keessatti kuufamu; admin dashboard, database, login fi maxxansuu online ofumaan hin qabu.
- Faayilota kana online maxxansuuf GitHub Pages, Netlify ykn hosting biraa fayyadamuu dandeessa.
- Maqaawwan barreessitootaa kutaa fakkeenyaa keessatti mul'atan fakkeenya dizaayinii ti; odeeffannoo dhugaa ta'uu isaanii mirkaneessi.
- Jechoonni kaka'umsaa fakkeenya yaadaa dha; maqaa hayyoota beekamoo waliin ragaa malee hin maxxansin.
